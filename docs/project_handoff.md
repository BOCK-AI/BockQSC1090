1. **Synthetic Data**: Many verification and simulation scripts generate synthetic data rather than running full physics simulations.

3. **DRC Checks**: The KLayout DRC checks in `klayout_quantum_processor.py` are placeholders.
4. **Z_GATE**: Fixed a bug where Z_GATE was defined as Identity in the dashboard.
