# Algorithm Blocks

The `algorithm_blocks/` directory contains predefined quantum routines:
- Grover's Algorithm
- Quantum Fourier Transform (QFT)
- Variational Quantum Eigensolver (VQE) using PennyLane
- Quantum Approximate Optimization Algorithm (QAOA) using PennyLane
- Bernstein-Vazirani
- Deutsch-Jozsa
- Simon's Algorithm
- Phase Estimation
